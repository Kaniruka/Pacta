# 法定节假日与调休数据（中国大陆）

## 内容

每个年份一个文件：`<year>.json`，由 `assets` 逐文件声明（README 不随包发布）。

```json
{
  "year": 2026,
  "days": [
    { "date": "2026-01-01", "kind": "holiday", "name": "元旦" },
    { "date": "2026-01-04", "kind": "workday", "name": "元旦" }
  ]
}
```

- `kind = holiday`：放假（含调休连休日）。
- `kind = workday`：调休上班（补班）日。
- 未列出的日期是普通日：没有休/班标记，只有旧历与节气。
- `name` 是所属节日。同一次连续假期整段共用首日的名字（2020-10-01 的「国庆中秋」会传播到 10-02…10-08），详情里的区间据此还原。

## 真实来源（务必按此理解）

- **口径**：国务院办公厅逐年发布的《关于……部分节假日安排的通知》。这是唯一权威口径。
- **落地方式**：本目录的 JSON 由 `lunar 1.7.9`（MIT，零传递依赖）内置的 `HolidayUtil` 表导出，生成脚本见 `.scratch/gen_holidays.dart`（本机过程文件，不入库）。
- **已核对**：2025、2026、2027 三年，放假集合与补班集合已与通知原文逐条全等比对（`test/plan/calendar_almanac_test.dart` 里以独立字面量断言，任一天多/少即失败）。
- **未核对**：2020–2024 尚未逐条比对通知原文，属于**待补证据**；这些年份只影响历史日期显示。
- **2028 起**：没有官方数据，不做规则推定。新年度通知发布后再补文件。

## 年度更新步骤

1. 打开中国政府网当年通知原文，抄录放假区间与上班日。
2. 生成本年 JSON（字段同上），只写有显式安排的日期；连续假期整段用首日名字。
3. 在 `calendar_almanac_test.dart` 的锚点用例里，用**通知原文**写死该年的放假集合与补班集合，跑 `flutter test test/plan`；集合必须全等。
4. 同步三处年份上限：`lib/src/plan/calendar_almanac.dart` 的 `lastHolidayYear`、`pubspec.yaml` 的 assets 列表、以及该测试的年份覆盖断言。
5. 跑 `flutter analyze` 与 `flutter test`（跨模块改动跑全量）。

## 边界

- 数据只影响休/班标记与详情文案；旧历与节气由 `lunar` 计算，不依赖本目录。
- 某年文件缺失时页面仍可用，只是该年没有休班标记。
