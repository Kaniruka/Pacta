# 法定节假日与调休数据（中国大陆）

## 内容

每个年份一个文件：`<year>.json`。

```json
{
  "year": 2026,
  "days": [
    { "date": "2026-01-01", "kind": "holiday", "name": "元旦" },
    { "date": "2026-01-04", "kind": "workday", "name": "元旦" }
  ]
}
```

- `kind = holiday`：放假（含调休连休日）。
- `kind = workday`：调休上班（补班）日。
- 未列出的日期是普通日，不放假设。
- `name` 是所属节日；整段假期共用同一个名字，用于在详情里还原「2月15日–2月23日」这类区间。

## 口径

- 唯一来源：国务院办公厅逐年发布的《关于……部分节假日安排的通知》。
- 覆盖：2020–2027（2027 年为截至 2026-11 已发布的最后一年）。
- 不预测未来年份。新年度通知发布（惯例为前一年 11 月上旬）后再补该年文件。

## 年度更新步骤

1. 打开中国政府网当年通知原文，逐条抄录放假区间与上班日。
2. 生成本年 JSON（字段同上），只写有显式安排的日期。
3. 用测试里的三个锚点年份（2025/2026/2027）方式校验：放假集合与上班集合必须与通知完全一致，多一天少一天都算失败。
4. 更新 `loadCalendarAlmanac` 的 `lastYear`，并补一条覆盖新年份的用例。
5. 跑 `flutter test test/plan`，确认旧年份断言未回归。

## 边界

- 数据只影响「休/班」标记与详情文案；旧历与节气由 `lunar` 计算，不依赖本目录。
- 某年文件缺失时页面仍可用，只是该年没有休班标记。
