## 已明确的本轮范围

- 看板目标和任务支持填写、编辑、展示简短描述，优先复用已有字段。
- 目标名称所在标题行支持展开/折叠，其他操作独立；保留状态提示，支持键盘与无障碍。
- 折叠目标内部所有添加入口隐藏，展开恢复。
- 先查清普通/精锐含义，未经确认不删除领域规则。
- 专注链完整任务列表倾向迁至二级页，主页面高度不随任务数量无限增长。
- 国策树视图选择跨进程重启恢复，需明确保存范围和默认值。
- 云同步常驻卡片简化，复杂操作点击后打开；右侧展示时间或状态，适配 Android/Windows。
- 进入 App 检查尚未处理的云端新数据并由用户选择；检查与执行分开，选择前不得改变本地业务数据。
- 云端来源记录并展示设备型号。

## 需求访谈时的事实与差距

以下代码位置与缺口记录于#64实施前；行号是当时的定位，不是当前代码承诺。描述字段的后续实现以`fece2f9`及验收记录为准。

### 看板与分类

- `lib/src/tasks/task_models.dart:26,70,133,140` 和 `task_database.dart:8,21` 均无目标/任务描述字段；编辑表单也无对应输入。产品设计 §2.3 有可选 notes，但尚无实现字段，不能直接声称可复用。
- `lib/main.dart:1426` 初始展开；`:1470` 标题 ListTile 无点击回调；`:1492` 独立图标切换；`:1520` 空目标提示不受折叠控制；`:1538` 添加任务不受折叠控制。内部添加入口只有“添加任务”；看板级“新建目标”不属于目标内部。
- 现行产品设计尾部和验收 B03 要求收起保留摘要和操作；本轮隐藏添加入口需把“操作”细化为保留编辑/删除等目标级操作。
- 普通/精锐具有三个层次：目标保存新任务默认分类；任务分类为普通/精锐/两者，用于组织筛选；本次专注模式决定此次记录归属。不是自动难度评估，不固定时长。
- `main.dart:1727,1750` 目标编辑字段已称“新任务默认分类”；`:2263` 分类筛选包含“两者”。GLOSSARY 的 Task Chain Classification / Focus Chain Mode 及核心规格 §任务分类支持此边界。
- 两条专注链有独立连续记录和失败范围，另有唯一预约链。修改分类不能迁移历史或改变进行中归属（验收 A02/A03）。

### 专注链与国策树

- `main.dart:1941` 专注链页面持有筛选、上次模式；`:1984` 汇总未删除且未完成任务；`:2148` 逐项把任务卡放进主页面 ListView，任务增多会把“我的链”推远。
- ADR 0004 已约定分类筛选位于二级任务选择页，现实现与其有差距。
- 当前筛选只有全部/精锐/普通；两者任务进入两个模式列表，没有“两者”专属筛选。列表未展示目标名和预计时长，与核心规格故事 11–12 有差距。本轮已按认可原型确定保留三筛选，补齐目标和预计时长。
- `main.dart:2276–2331` 按模式筛选或上次模式打开设置，已有流程时优先恢复；设置中可切换本次模式。`focus_repository.dart:1431–1451,2482–2490` 专注开始持久化上次模式，首次普通；`:1090–1127` 预约开始只保存预约自身模式，未更新上次模式偏好。Q13 已确认两种成功启动统一更新上次模式；现状只作为静态差距，不记为已实机复现缺陷。
- `national_focus_tree_page.dart:53` `_detailed = false`；`:487` 切换仅 setState。静态定位：缺少持久化读写，页面状态重建即恢复简洁。
- 现有国策页面测试覆盖本次页面内切换，未提供真实进程退出重启的恢复证据。本次尚未进行 Android/Windows 冷重启复现，不能把静态证据当作设备验收。

### 云同步

- GLOSSARY、ADR 0005、验收 A16–A19 定义用户明确选择整份上传/下载覆盖，不逐记录合并；被覆盖快照的独有记录丢弃。设备设置、认证、管理员状态不在业务快照内。
- 验收“2026-10-04 手动云同步补充”明确启动/前台/网络恢复不触发云业务读写。本轮自动检查需要明确修订这一限制；不等于授权自动覆盖。
- `cloud_sync_card.dart:23` 点击检查，`:37` 弹出方向选择对话框，`:89` 第二次覆盖确认，`:112` 执行上传或下载。复杂选项已经放在点击后的对话框中，当前要改的是常驻摘要和弹层形态，不能描述成目前所有选项常驻。
- 卡片 `_message` 只是内存消息，无持久化的“本设备上次成功同步时间”。云端 uploadedAt 是云端接收快照时间，不等于本机上次同步时间。
- `cloud_snapshot_repository.dart:67` 新版检查只取 revision、来源、时间、记录数；无新版快照时转读旧表并在隔离内存库转换，不写本机业务表。自动检查若要求仅取元数据，旧版分支需另行设计。
- `main.dart:132` 来源是主机名 + Android/Windows；不是硬件型号。已有 device_id、device_name，可保留旧名称并增补型号，不能把未知旧值伪装成型号。
- 新版 revision 可用于检测版本变化；本地 fingerprint 用于覆盖前防止预览过期，但没有持久化“已处理/已忽略云版本”的完整提醒机制。
- `cloud_snapshot_repository.dart:440–518` 覆盖前校验本地指纹和云版本，下载事务替换且禁止中断未结束专注/预约。新提醒应复用这些保护。
- 旧数据缺设备和上传时间时明确标未知；检查没有本地业务时间的空快照目前回退当前时间（`:420–437`），不宜将它当真实编辑时间或更新依据。

## 首轮已确认决策（2026-10-22）

用户接受首轮推荐方案；第二轮明确拒绝云更新的按钮仅命名“忽略”，其作用限于停止该版本主动提醒；Q10 正常状态只显示上次同步时间，不显示方向。

1. 描述：可选、可清空、去首尾空白；空值不占行；最多 200 个用户可见字符；输入单段，粘贴换行变空格；展示一行省略，编辑可看全文。目标折叠仍显示目标描述，任务描述随任务隐藏。
2. 折叠：移除独立可聚焦折叠按钮，以标题区域与非独立焦点箭头控制；编辑/删除独立；空目标也可折叠并隐藏空态和添加入口；初始展开，暂不增加跨启动折叠记忆。Tab、Enter/Space、可见焦点和展开状态朗读均需验收。
3. 分类：保留两条链和任务分类；看板目标摘要移除易误解的分类标签，目标编辑仍称新任务默认分类，任务编辑称适用专注链；看板任务行不再常驻分类标签，任务选择页保留筛选。
4. 专注链：主页面保留未完成流程恢复、可选任务数量、选择任务入口、链摘要及历史；不展示任务预览列表。二级页选择任务进入时长/模式设置，取消返回列表并保留筛选/滚动；开始后进入专注/预约，退出执行页回主页面。已有未结束流程优先恢复，不开启第二个流程。
5. 视图偏好：本机当前用户隔离、不上云；首次简洁，切换即存；恢复优先读取保存值；失败回退简洁并允许重试。仅保存简洁/详细，不扩展为缩放和平移持久化。
6. 更新检查触发：冷启动及返回前台检查，前台检查节流 5 分钟；离线失败不阻断、不弹错误，卡片可重试。应在登录和可访问用户状态确认后执行。
7. 更新判定：以当前用户云版本是否未处理为准，不只比较设备时间；自己上传及已经下载的版本不提示。首见已有云快照也提示，旧版使用稳定版本标记并单独标注来源未知。
8. 拒绝提醒：同一云版本明确选择“忽略”后不再主动弹出，该版本在卡片保留；出现新版本才提醒。处理标记本机按用户保存，不随业务下载覆盖。按钮名称仅为“忽略”，只作用于当前云版本。
9. 本地变化与同步语义：沿用整份覆盖；本地有未同步修改时明确提示及说明丢弃后果，不自动上传/下载，不默认选方向。有进行中流程时可检查提示，但下载须先结束流程。“忽略”只停止当前版本的主动提醒，不能替代覆盖确认中的丢弃后果说明。
10. 平台呈现：Android 底部弹窗；Windows 采用居中限宽对话框承载相同内容。卡片右侧优先显示处理中/失败/云端待处理；正常状态仅显示本机上次成功同步时间，不附方向，无记录显示尚未同步。检查成功不刷新同步时间；设备重启后仍可显示该时间，按本机当前用户隔离。
11. 设备型号：Android 品牌+型号，Windows 厂商+机型并保留可辨识设备名；无法获取标型号未知，保留原设备名。旧快照不回填虚假型号。只记录必要设备信息，不收集序列号。

## 第二轮已确认决策（2026-10-22）

- Q12：“忽略”只表示不再主动提示该云版本，不上传、不下载、不改本地；进入同步弹层仍能处理。选择上传或下载时仍明确说明目标端独有记录会被替换、丢弃，不能用“忽略”掩盖此后果。
- Q13：记住最后一次成功开始预约或直接专注时选择的模式；仅切换设置或取消不改变跨次默认。全部筛选用该模式，首次普通；精锐/普通筛选预选对应模式，设置仍可切换。预约后来取消不撤回已记住的选择。
- Q14：有进行中的预约、专注或暂停时照常进行只读云检查，但只展示不遮挡操作的更新提示；自动选择提示延迟到流程结束，除非已忽略或已有更新版本。用户主动打开同步仍可查看/上传，下载继续禁止。
- Q15：只有明确点“忽略”才停止该版本主动提醒；关闭弹层、返回或按 Escape 仅关闭本次提示，不作忽略，下次满足检查条件时可再提醒。手动同步弹层的取消始终不执行传输。

Q1–Q15 已全部确认，已同步产品设计、核心规格、验收矩阵及 ADR 0005。用户已确认最终摘要代表共同理解；该确认不自动授权进入业务实现。
