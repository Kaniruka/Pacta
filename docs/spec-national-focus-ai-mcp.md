# 国策树只读 AI 分析：远程 MCP、Codex skill 与 App 引导

本文是 2026-10-20 确认的整体目标规格，验收要求覆盖多个子 Issue。当前已实现范围和验证结果见 [MCP 合同](../supabase/functions/national-focus-mcp/README.md)及 [#57](issue-57-validation.md)、[#58](issue-58-validation.md)、[#59](issue-59-validation.md) 验收记录；本规格不表示全部能力已经交付。

## Problem Statement

用户在手机维护国策，希望 Codex 审视规则、父子关系和执行负担，并依据失败历史提出调整建议。目前只能转述或提供截图，缺少结构、历史规则和证据接口及使用引导。

国策独立于目标/任务，现实履行由用户判断；AI 须保留用户决定权，防止越权读取和误写。

## Solution

向每位正常用户提供独立授权的远程只读 MCP：手机维护 → 手动上传整份业务快照 → Codex 读取其中的国策数据并结合 skill 分析。手机上传后无须保持 App 运行，首轮由需求提出者验证。

“我的”提供“国策 AI 分析”入口，国策树更多/帮助进入同一引导页，保留四个主目的地。

## User Stories

1. 在 App 发现分析入口并开始使用。
2. 从国策树直达同一引导页。
3. 授权前了解数据范围和只读限制。
4. 明确“维护→手动上传→提问”，手机修改不会自动进入分析。
5. 上传沿用整份覆盖确认，理解它会替换云端整份业务快照。
6. 复制服务地址，按受支持 Codex 客户端的步骤连接。
7. 登录 Pacta 后明确授予国策只读权限。
8. 有效授权期间重复读取，无须重新配置。
9. 在 App 查看、撤销自己的连接，阻止后续读取。
10. 知道撤销不能收回已进入 AI 对话的数据。
11. 按引导安装/启用 skill，复制示例问题。
12. 读取完整树和稳定卡片标识，区分同名卡及父子关系。
13. 读取卡片库、基础规则、强化等级和要求版本，区分当前/历史要求及候选卡。
14. 读取点亮/待今日确认/真正熄灭状态、连续记录和内化进度，了解当前背景。
15. 审视规则具体性、依赖合理性和负担，改善规则设计。
16. 依据失败事件、当时树快照和原因复盘。
17. 区分独立失败、漏确认与连带熄灭，避免重复计数。
18. 区分原始原因与事后可编辑反思。
19. 每次获取来源设备、上传时间和版本，判断数据时效。
20. 无云快照时获知如何到 App 手动上传。
21. 授权过期/撤销、停用或网络错误有恢复指引，不冒充空树。
22. 分开事实、可能解释和建议，引用卡片/历史记录以供复核。
23. 数据不足时说明限制，不虚构成功日历或因果结论。
24. 自行决定并在 App 采纳建议，AI 不修改规则、位置或记录。
25. 每位用户独立授权，只能读取自己的国策。
26. 分析中新上传不能导致静默混用不同版本。
27. 按时间范围分页查询历史，逐步分析大量记录。

## Implementation Decisions

- 沿用单 Supabase 项目、用户隔离、Android/Windows、四目的地及手动整份同步决策；国策不变为目标/任务层级。
- 仅读取最近一次手动上传的 Cloud Data Snapshot。编辑、连接、调用工具和打开引导均不触发业务上传/下载/合并或国策结算；更新数据须用户手动同步。
- 优先验证 Supabase Edge Functions 的协议、部署及 Codex 认证兼容性；替代承载须记录依据并保留远程访问和授权行为。推理由 Codex 完成，App 不接模型 API。
- 工具覆盖快照信息、树/库/规则详情、分页失败查询；实施时确定名称、输入输出及版本合同。禁止任意 SQL、任意表读取和业务写入工具。
- 白名单：树结构/状态、独立卡片库、名称/规则、强化等级、要求版本、连续记录、内化进度、失败事件/冻结树快照/原因/后续反思。历史软删卡保留历史语义，不当作当前树卡。
- 所有返回值（含嵌套快照）排除目标、任务、专注、日历、认证及管理员信息；混合模块来源日志不得透传。
- 每次返回 revision、来源设备和真实 uploaded_at，标明“最近上传”；派生更新时间不冒充国策最后编辑时间。旧版缺失元数据标未知，不展示哨兵时间。
- 无规范快照或仅有旧版数据时，指引使用现有客户端手动上传；MCP 不迁移或写云数据。正常空树与读取错误分开。
- 后续详情/分页约束预期 revision；变更时明确报错并重新取数、分析，不混用版本，不新增长期历史云快照存储。
- 登录 Pacta 并明确授权后，建立仅国策只读的独立委托；无需把凭据贴进对话。提供 Codex 兼容认证、到期/续期、撤销及注明有效期的使用文档。
- 每次请求校验授权、所属用户和正常用户状态；App 撤销后后续请求须失败，即使普通 JWT 尚未到期。不得向 Codex 提供管理员密钥或完整应用会话。
- RLS 负责用户隔离，另加委托权限和国策字段限制；只读标记/skill 不替代安全实现。授权存储和受限查询通过迁移实现，保持原快照同步语义。
- 引导页包含用途/范围、手动上传入口/步骤、可复制 MCP 地址和 Codex 配置、授权状态/撤销、skill 安装/启用、首次问题、时效及无快照/旧数据/过期授权等恢复说明；离线/无云配置有提示，复制内容不含密钥。
- 上传入口进入现有同步预览/覆盖确认，连接不隐式上传。查看授权/元数据可查询服务，但不把业务快照下载到设备或修改业务记录。
- skill 解释 RSIP 用户自主判断、三种状态、北京 04:00 检查点、强化等级与内化进度、独立/连带失败和历史要求版本；输出事实、可能解释、可执行建议及证据。不得判定现实履行、测量真实习惯形成或证明失败原因。
- 历史先提供可信失败事件、冻结快照和要求版本；累计成功量不是每日成功日志。来源日志仅可经验证后重建，不能假定完整性、顺序或设备时钟可靠；不承诺完整成功日历/编辑史。
- 历史查询有界、可分页；skill 默认复盘近 30 个国策日，可查更早记录，不过滤当前树/规则。返回实际覆盖范围、截断/下一页信息；缺失记录不得虚构。

## Testing Decisions

- 已确认主边界为公开 MCP；补充 App 引导/撤销和隔离项目真实服务验证。复用快照/App-shell 注入边界，新增边界集中在 MCP 入口；测响应和持久数据变化，不绑定内部函数、SQL 拼写或框架。
- 契约夹具：两用户、含全部模块的快照、同名卡、多强化/要求版本、独立/连带失败和事后说明。验证投影、稳定引用、元数据、版本一致性，并递归检查无范围外数据/凭据。
- 公开入口覆盖未授权、越权、伪造用户、过期/撤销/停用、无快照、空树、旧格式、无效输入、服务错误、分页越界和新上传变更；错误不冒充空结果，后续查询不混版本。
- 重复读取无写入、计数变化或上传/下载/结算；断网/服务恢复可重试，不影响离线业务和显式同步。
- 复用整份快照仓储/手动同步 App 测试，验证覆盖确认、用户隔离；国策仓储测试作为状态、版本、检查点及失败语义先例。
- 在隔离 Supabase 项目验证真实认证、撤销、跨用户、停用、只读与 RLS，参考现有快照/国策事务回滚脚本；RLS 不替代委托权限测试，不使用生产用户夹具。
- App-shell/widget 覆盖两个入口、无密钥配置复制、上传导航、错误、授权/撤销、窄/宽屏、大字号及可访问操作，参考现有同步/设置页测试。
- Android/Windows 均验证引导；至少一次真实 Codex 端到端覆盖连接→授权→取数→skill 分析→再次上传后重读→撤销后拒绝，记录版本和环境。平板具体客户端经验证后才声明支持。
- skill 合成数据覆盖事实/推测分离、引用、同名卡、父失败连带、漏确认、规则版本、事后反思和不完整历史；不逐字匹配模型输出。
- Dart 改动执行格式化、分析和相关测试，跨模块跑完整 Flutter 测试；仅报告实际命令/平台/结果，本规格不代表已执行功能验收。

## Out of Scope

- AI 写回：增删卡、移动、点亮/确认/熄灭、修改规则/进度/失败历史。
- 本机 MCP、手机常驻、自动上传/同步、记录合并。
- 其他模块 MCP、跨用户共享、通用数据库管理工具。
- App 内模型聊天/模型 API、自动规则评估或真实习惯形成判定。
- 完整逐日成功日志/编辑审计重建、永久云快照版本存储。
- 新增 Android/Windows 之外的 Pacta 平台或承诺未验证的 Codex 客户端。
