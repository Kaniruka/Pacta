# 专注链页面设计改进（2026-10-07）

## 问题与方向

上一版把三种动作铺成设置表放在页首，任务入口被挤下；动作与连续记录分处两张卡，需要来回关联。这是界面结构问题。Android/Windows Flutter Material 3 页面的职责是开始或恢复本次专注，并查看跨任务链记录。

优先显示未完成流程及任务启动区，随后展示“我的链”：每条专注链把自己的动作、当前/最佳连续记录、累计和平均时长合在一张卡；预约链保留独立而紧凑的动作和记录。编辑入口从独占一行的长按钮收敛为有标签的按钮。时长口径在链卡下只保留一行简短说明。不新增链、不改变启动/失败/交接规则。

## 布局与视觉

小屏：标题 → 进行中流程（如果有）→ 开始一次专注（筛选、任务）→ 我的链（精锐、普通、预约）；历史入口位于标题旁。
宽屏：相同顺序，精锐/普通可并排；放大文字或不足宽度时垂直排列。

沿用 Pacta 的绿色语义主题、系统字体与 Material 控件，不建立另一套调色板。容器保持安静，连续次数为链卡内视觉重点；累计与平均并排或换行。无新增动画、模糊或装饰性进度。组间24–28、卡内20、内容间8–12逻辑像素；编辑触控目标至少48。

本方案的产品特征来自三个真实独立链及其承诺动作，而非通用数据看板。删去原来的独立“神圣座位”设置墙与“连续记录”列表，避免同一条链的信息跨区重复。

依据 apple-design 已读参考：layout.md › Visual hierarchy “Order content by relative importance”、 “Group related items”；layout.md › Adaptability “Be prepared for text-size changes”；buttons.md › Best practices 的44×44触控原则转译到Material的48逻辑像素。Android使用这些基础原则，不套用iOS导航或玻璃材质。
