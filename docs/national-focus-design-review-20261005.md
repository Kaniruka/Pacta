# 国策树设计审查与实施决定（2026-10-05，2026-10-06验证）

## Summary

初版评价 Needs work；实施后评价 Good。页面的单一职责是扫描当前国策、理解父子关系并完成每日维护。原节点280×170、详情280×730将内容和管理操作压进画布；最终简洁节点148×100、详细节点210×124（高度支持文字缩放），以圆形状态图标、独立名称和分支连线为视觉主轴。真实Android中文字体截图已检查；Windows鼠标/滚轮与窄宽视口通过Widget测试，未把它冒充真实Windows键盘验收。

平台为Flutter Material 3的Android/Windows。Apple HIG在这里用于可访问性、层次与渐进披露原则，组件使用Material，未套用iOS导航或Liquid Glass。

## Improvements 已实施

- **High / 画布负载**：`layout.md › Visual hierarchy`：“Use progressive disclosure to make layouts cleaner and easier to interact with.” 简洁模式只保留圆形状态图标与名称，详细模式增加当前有效行动的一行摘要，大字号可扩展为两行。点击底部操作面板，完整规则和记录在“查看详情”中展开，不推移树节点。
- **High / 日常动作层级**：`toolbars.md › Actions`要求优先支持主要任务。页面固定标题栏放今日确认与待确认数、卡片库和更多菜单；检查点及失败记录由更多进入二级页。顶部窄屏与大字号用Wrap换行。具体位置及文案为本次产品设计判断。
- **Medium / 操作组织**：`menus.md › Organization`：“Prefer listing important or frequently used menu items first.” 面板先展示状态动作与详情，随后强化、名称、添加子节点、调整位置；熄灭与移入卡片库在末尾。移入库仍确认整个子树移入并解除父子关系，使用可恢复的库操作语义，不误称删除。
- **High / 可辨识性约束**：`accessibility.md › Vision`：“Convey information with more than color alone.” 点亮、待今日确认、熄灭和待核对有不同图标与Semantics文字。圆图标40dp，点击区域是整个节点，100%视图超过Material 48dp目标；整树缩小时可通过缩放控件恢复可读尺寸。320dp宽/200%字号的节点与面板验证通过。此项是设计验收约束，未把未测TalkBack全流程报告为已验证。

## 用户已确认的领域与交互决定

国策卡新增独立必填名称，允许重名、可改名。名称不随强化等级变化，修改名称不建立要求版本，不重置连续记录或内化进度。新失败快照保存事件当时名称。详细模式的描述使用当前有效行动，不新增描述字段。

添加子节点进入国策卡片库，可选已有卡或新建；返回后自动挂到发起节点下，不再选父节点，不自动点亮；新卡为熄灭，已有库卡沿用现有待确认/熄灭状态。标题栏进入卡片库仍使用正常选位置流程。手动点亮、父级熄灭门槛、子树移入库关系解除、北京04:00检查点和批量只处理待确认节点等业务语义保留。

用户说明当前无正式用户，授权删除旧开发数据和测试身份，只保留唯一管理员。已实际执行一次性管理重置，证据见 `development-reset-20261005.md`；不在产品升级中自动擦除数据，不为无名称旧卡随意回填名称。非空旧国策库明确拒绝升级，空旧库可添加名称列并保留其他领域数据。

## 视觉与布局

保留现有种子色#385A52与系统Material字体，使用语义颜色，不新建重复调色板。节点标题使用titleSmall（14sp），摘要使用bodySmall（12sp），面板标题使用headlineSmall（24sp）；完整内容可滚动与文字缩放。图标、父子线与名称承担层次，移除节点内独立详情按钮、状态chip及快捷操作栏。

紧凑宽度：固定标题栏→密度切换→树画布；宽屏保持相同功能并扩大画布。示意：

```text

国策树  今日确认  库  ⋮       国策树             今日确认  库  ⋮
简洁 / 详细                  简洁 / 详细
[− 100% + 整树]             [− 100% + 整树]
       ○ 名称                        ○ 名称
      /     \                     /       \
   ○ 名称  ○ 名称               ○ 名称     ○ 名称
```

签名元素是清晰分支和圆形状态节点，来自国策树的主题。导航与维护使用熟悉组件，不增加装饰动画；保留用户控制缩放/平移。50节点整树模式用于观察结构，需要放大阅读个别卡名；完整名称和规则在点击面板可读。

## What works

父子连线、两种密度、手动确认、卡片库与历史保留。圆形图标让三态更简洁，树的视觉结构不因打开详情变化。名称与规则分开后，强化不再让节点标题变成越来越长的触发条件。
