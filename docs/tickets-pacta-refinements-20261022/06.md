# T06: 简洁同步卡片与可持久的安全同步结果

状态：已发布 [T06 / #69](https://github.com/Kaniruka/Pacta/issues/69)，标签 ready-for-agent；原生父子和阻塞关系已核验。待实施、未验收。

## Parent

https://github.com/Kaniruka/Pacta/issues/63

## What to build

同步卡片以时间/状态摘要呈现，在适配平台的弹层内完成现有整份覆盖，并记住本机同步结果。

## Acceptance criteria

- [ ] Android底部弹窗、Windows居中限宽对话框承载查看、明确选方向和覆盖确认；可返回/Escape退出，窄布局/大字号/键盘可用。
- [ ] 正常右侧只显示本机当前用户上次成功同步时间，不附方向；无记录尚未同步，工作/失败/已知云端待处理优先。
- [ ] 仅成功上传或下载才持久化成功时间及用于识别本地后续修改的可靠基线；检查、取消、忽略、失败不刷新成功时间；未知历史基线不冒充本地无修改。
- [ ] 保留整份覆盖、双方时间和来源、不默认方向、丢弃后果说明；本地未同步修改明确警告。进行中流程可上传、禁止下载，过期预览重查，失败保留原目的端。
- [ ] 为后续版本检查提供同一按设备/用户隔离的成功同步版本状态；不把设备设置放入业务快照。
- [ ] Android15/Windows11各验证完整弹层操作、成功后进程重启时间恢复及只检查不更新时间；隔离Supabase验证本地变化/并发拒绝/权限与失败不部分覆盖。

## Blocked by

None (can start immediately)

## Validation notes

App级同步测试和现有快照事务测试为先例。云端待处理在本票支持已知状态呈现；自动发现由检查票交付，不先建横向状态框架票。

仅陈述目标与验证要求；本轮未运行任何实现测试或设备验证。实施时按项目要求format、analyze及相关test，跨模块变更跑完整test；保留用户数据，真实服务使用隔离项目。
