## What to build

按认可原型将完整任务列表迁入二级页面，主页保留数量、入口、链记录、历史和现有流程恢复。

## Acceptance criteria

- [x] 主页不渲染任务预览列表，任务再多也不无限增高；可选数量仅计未删除且未完成任务。
- [x] 二级页提供全部/精锐/普通筛选，两者任务进入两个模式列表；条目显示目标、分类、预计时长和专注进度，无预计时长显示未设置。
- [x] 选任务进入设置；取消/返回列表保留筛选和滚动；开始进入预约/专注执行，执行页返回专注主页且流程继续。
- [x] 已有活动/暂停会话或预约时优先恢复原流程，不创建第二流程；原任务后来完成/删除也能恢复已有流程。
- [x] 原型只作已确认导航参考，排除示例数据、演示按钮/参数，不改变计时、失败、暂停、15分钟预约交接等现有规则。
- [x] Android15系统返回/触摸与Windows11键盘/鼠标/窗口缩放验证浏览、取消、启动、恢复全路径，两端包含大量任务和大字号。
