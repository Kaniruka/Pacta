## What to build

## Acceptance criteria

- [ ] 首次发现已有云快照提示，不因云端数据时间较旧而跳过；自己上传/已下载不提示，不默认选择同步方向。
- [ ] 按钮仅称忽略；按本机用户持久化当前版本忽略标记，跨进程重启不再主动提示且仍可手动处理；新版本可再提醒，下载业务快照不覆盖标记。
- [ ] 关闭/返回/Escape不等于忽略，下次满足检查条件可再提醒；忽略、关闭和检查都不改本地业务数据。
- [ ] 预约/专注/暂停期间只给非阻断提示，流程结束后再提示选择；期间已忽略/已处理则不再提示，若版本更新只处理最新可用版本，不弹过期提示。
- [ ] 主动查看/上传仍可用，下载仍需结束流程；选择上传/下载继续完整预览和覆盖确认，本地未同步修改及独有数据丢弃必须明确。
- [ ] Android15/Windows11真实验证首次/同版/新版、忽略后重启、关闭后再次前台、活动/暂停/预约及结束后提示；隔离Supabase双端变化与旧数据稳定标记验证。
