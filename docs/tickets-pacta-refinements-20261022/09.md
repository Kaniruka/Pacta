- [x] 首次发现已有云快照提示，不因云端数据时间较旧而跳过；自己上传/已下载不提示，不默认选择同步方向。

- [x] 关闭/返回不等于忽略，下次满足检查条件可再提醒；忽略、关闭和检查都不改本地业务数据。
- [x] 预约/专注/暂停期间只给非阻断提示，流程结束后再提示选择；期间已忽略/已处理则不再提示，若版本更新只处理最新可用版本，不弹过期提示。
- [x] 主动查看/上传仍可用，下载仍需结束流程；选择上传/下载继续完整预览和覆盖确认，本地未同步修改及独有数据丢弃必须明确。
