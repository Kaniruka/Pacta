- [ ] 登录及可访问用户状态确认后冷启动检查；返回前台按5分钟节流，不新增普通编辑/网络恢复自动传输。

- [ ] 依据云版本而非时间新旧；自己上传和已成功下载的版本标为已处理，不误报；用户切换后不显示上个用户检查结果。
- [ ] 离线/失败不阻断、不弹错误对话框，卡片状态可重试；未选择前上传/应用下载均未执行，本地业务内容保持不变。
- [ ] Android15/Windows11真实冷启动、前台/后台和断网重连操作取证；隔离Supabase验证新快照与旧数据检查、用户隔离和版本变化。
