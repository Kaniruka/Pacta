## What to build

## Acceptance criteria

- [ ] 标题区域触摸/鼠标可切换，箭头表示状态且不形成第二个折叠焦点；编辑删除独立，不误触折叠。
- [ ] 空/非空目标折叠均隐藏任务、内部全部添加入口和空态提示；保留标题、数量、完成状态及目标级编辑删除；展开恢复，各目标独立，首次展开。
- [ ] 提供Tab焦点、Enter/Space和展开状态语义；隐藏内容不再能被键盘或读屏操作。
- [ ] 看板目标/任务行不常驻分类标签；目标编辑称新任务默认分类，任务编辑称适用专注链；不改普通/精锐/两者规则、进度和历史归属。
- [ ] Android15触摸/TalkBack、Windows11鼠标/键盘/可用读屏及两端窄布局大字号验证；描述票落地后再复核折叠仍保留目标描述、任务描述隐藏。
