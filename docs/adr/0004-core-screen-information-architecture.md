# Use a four-destination shell with a task-first Board

Chain will use four primary destinations: Board, National Focus Tree, Focus Chain, and My. Board is the first landing surface and combines the App-owned Task list with Focus Progress, National Focus status, and Recent Focus Activity; a separate To-do or data-dashboard destination is not part of the primary navigation. National Focus Tree remains a structural canvas with Card Library and daily-confirmation actions, while Focus Chain owns task selection and session setup. Elite and Regular are task-classification filters in a secondary task-picker rather than separate primary pages. A Focus Session then moves to a dedicated countdown surface whose normal completion occurs only at countdown zero; exception controls route through Precedent Rule or Failure Reason flows. This boundary keeps the first action visible, preserves the distinct tree and focus models, and prevents the reference UI from turning into a general project-management app.

The accepted reference for the composition and interaction sequence is `prototype/pacta-own-shell-v4.html`; it is intentionally a throwaway prototype and does not define production Flutter components.
