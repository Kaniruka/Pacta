# 大字号适配与专门键盘操作退出产品范围

产品负责人于 2026-10-23 确认长期收窄 Pacta 的 UI 支持范围：保留正常字号可读性、响应式布局及鼠标／触摸操作；大字号适配、专门键盘操作支持及其相关专项测试退出产品范围，不作为后续实现、评审或发布验收条件。这是长期范围取舍，不是暂缓交付，后续执行无需再次确认。

## 适用边界

- 退出的要求包括系统字体放大、两倍或极大字号适配，以及专门的键盘导航、快捷键、键盘退出、Tab 可达性、Enter/Space 激活、键盘焦点可见性和焦点顺序专项支持与测试。普通文本输入继续属于正常产品操作；本决定不取消表单输入、移动端输入法或输入时布局可用性。
- 保留正常字号下的可读性、状态文字与图标、亮暗主题、窄宽屏和可调窗口响应式布局、长文案处理、鼠标点击／滚动及触摸操作。页面返回、弹层取消及恢复等行为仍须可通过现有鼠标／触摸入口完成；Android 系统返回要求继续有效。
- 项目与外部技能的大字号、键盘建议均服从本决定。后续代理不据此新增专项实现／测试、报告范围内缺陷或阻塞交付；通用技能无需为 Pacta 单独改写。其余适用的功能检查与项目测试规则继续执行。既有测试可随常规测试执行并如实记录；仅涉及已退出范围的专项断言不再单独构成验收门槛，影响保留范围内行为的失败仍须处理。

## 替代范围

本决定**仅部分替代** [ADR 0007](0007-accessibility-out-of-product-scope.md) 中“大字号及 Windows 常规键盘操作继续保留”的条款；该 ADR 关于读屏、Semantics 与辅助技术退出范围的决定继续有效。ADR 0003 的平台选择与 ADR 0004 的导航职责不变。

同时替代此前以下资料中将大字号或专门键盘支持列为现行条件的部分：

- UI 指南、代理指引及技能带入的实现／设计评审／发布验收要求。
- 核心规格、产品设计、国策画布当前方案、国策 AI 规格，以及改进专题规格的用户故事 12、40、云弹层要求和 Testing Decisions。
- 验收矩阵 R22-01、R22-02 及关联场景中的同类要求；#63 与相关未完成 Issue，包括 #69 的 Escape／大字号／键盘验收条款。
- 较早需求决定、已完成票据及历史审查中仍被引用的同类要求，只能作为其形成时点的范围与事实，不形成未来交付门槛。

## 历史与实现保留

已有实现、测试、截图、审查和有日期的验收记录原样保留。本次只同步文档与票据，不删除或修改代码、测试，不将过去未执行的检查追记为通过，也不撤销过去已执行的结果。现有键盘或字体缩放能力可以继续存在；退出范围不授权将其删除。未来若恢复这些专项要求，需要新的明确范围决定。

文档与未完成票据同步结果见[范围同步记录](../input-scope-change-20261023.md)。
