## What to build

## Acceptance criteria

- [ ] 开关按本机用户保存，默认关闭；单次及批量确认成功触发，普通编辑不单独触发。
- [ ] 整批只发起一次上传；重复重试不重复创建同一请求的备份。
- [ ] 离线不影响确认，待上传状态跨重启；联网后上传最新有效快照并做版本检查。
- [ ] 未处理云版本停止自动覆盖，忽略提醒不等于覆盖授权；无自动下载。
- [ ] 关闭开关、切换账号及恢复旧备份不继续执行旧请求；生命周期不可访问时不得传输。
- [ ] App级测试覆盖冲突、失败、重试、账号隔离与批量例外确认；真实云两端往返验证。
