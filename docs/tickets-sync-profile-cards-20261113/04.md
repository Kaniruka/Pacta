状态：ready-for-agent；用户已确认发布及完整实施。

## Parent

https://github.com/Kaniruka/Pacta/issues/90

## What to build

编辑头像昵称并跨设备使用，在我的页面展示两组统计且可进入详细记录。

依据：[规格](../spec-sync-profile-cards-20261113.md)及[需求确认](../requirements-sync-profile-cards-20261113.md)。

## Acceptance criteria

- [ ] 头像昵称使用账号资料，缓存离线可见；保存失败可重试，头像通过系统选择器选取。
- [ ] 资料资源按用户隔离，业务备份恢复不回滚资料；清除生命周期覆盖头像资源。
- [ ] 当前点亮数仅树中未删除Lit卡片；已内化数量按未删除卡片累计成功日达到180天计数。采用已确认归一化指数公式，180天达到100%并封顶。
- [ ] 专注完成次数与累计有效时间采用规格明确口径；空记录为0，详细记录可达。
- [ ] 已内化不改变强化要求或结算；覆盖179/180天边界、封顶、显示舍入不提前计入和历史成功日不变。不引入社交统计；沿用现有主题、字体和其他我的页能力。
- [ ] 测试跨用户、上传失败、缓存、统计边界与恢复后的刷新；真实云资料隔离及两端布局验收。

## Blocked by

无；公式已确认并在模型中单独实施，其余名片功能仍待整体实施。
