# 02：简洁同步与最近15份备份恢复

状态：ready-for-agent；用户已确认发布及完整实施。

## What to build

简化同步入口和来源格式，贯通上传生成历史备份、列表、恢复前保护及指定版本恢复。

依据：[规格](../spec-sync-profile-cards-20261113.md)及[需求确认](../requirements-sync-profile-cards-20261113.md)。

## Acceptance criteria

- [ ] Android来源为型号（Android），Windows为设备名（Windows）；不单列ID、厂商。
- [ ] 首页保留本机成功同步时间；覆盖提示按需展示时间和后果，失败或检查不冒充成功。
- [ ] 包含最新份在内保留最近15份成功云备份；原子写入与淘汰，迁移不丢现存快照。
- [ ] 列表提供时间、来源、记录数；恢复前持久保存可找回的本机恢复点，失败不替换。
- [ ] 恢复不自动覆盖云端；保持活动流程下载阻断、版本检查、用户隔离及旧格式兼容。
- [ ] 隔离云项目验证RLS、并发、保留上限、恢复和生命周期清除；完成两端页面验收。
