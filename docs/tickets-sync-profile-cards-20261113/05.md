## What to build

集中已有提醒，新增每日打开Pacta的独立定时提醒，在使用功能时申请相应权限。

依据：[规格](../spec-sync-profile-cards-20261113.md)及[需求确认](../requirements-sync-profile-cards-20261113.md)。

## Acceptance criteria

- [ ] 整合专注／预约与国策待确认提醒，显示授权及开关状态。
- [ ] 每日打开提醒独立开关与时间，默认关闭、首次开启选时间；本机当地时间每天一次，点击打开看板。
- [ ] 修改时间、关闭、重启、跨日、时区变化不导致重复旧提醒或补发多日积压。
- [ ] 通知／日历按需申请；拒绝可继续核心操作，不可重复请求时提供系统设置入口。
- [ ] 普通通知与精确闹钟授权区分；设置属本机当前用户，不随业务快照覆盖。
- [ ] Android及Windows分别验证权限、通知到达与点击、后台和退出行为；准确说明平台限制，邮箱提醒不实现。
