# 国策树画布与二级导航（2026-10-04）

依据：用户提供的 V.13、8.18 国策树图片，以及 ADR 0004 与核心规格 38–42。平台为 Android/Windows，采用 Flutter Material 3；Apple HIG 在这里作为可访问性和交互原则参考，不套用 Apple 平台导航样式。

## 设计判断

原结构视图仍展示长规则文本、状态和多种维护操作，节点高度随内容变化，主页面还有可展开的记录内容。整树难以扫描，父子关系容易被卡片面积淹没。改为以二维结构画布为主，细节逐步展开；日常确认保留在树页面，检查点/失败记录、专注历史和用户管理进入带标准返回按钮的二级页。

参考已读取的 apple-design 本地文件：`scroll-views.md › Best practices` 明确要求支持缩放时设置合理的最大最小比例；`toolbars.md › Navigation` 要求标准返回按钮；`layout.md`、`accessibility.md`、`typography.md`、`color.md` 作为响应布局、文本和控件可访问性的依据。画布中的层次布局和父子连线是本次产品设计判断。

## 视觉与布局

沿用现有 `ColorScheme.fromSeed(#385A52)` 的亮/暗语义配色，不引入独立调色板。画布使用 surface，正文使用 onSurface，连线使用 outline，交互使用 primary。保留系统字体和现有 Material 字号；规则全文不缩写存储，只在结构视图渐进披露。状态同时有文字和图标，避免仅靠颜色表达。

紧凑宽度：标题/卡片库 → 今日确认与记录入口 → 结构/详情 → 画布工具 → 二维画布。
宽屏：同一功能集，画布扩大，占据主要内容区域。

签名元素是清晰的树分支连线和整树视角，来自国策树本身的结构，而不是额外装饰。缩放和平移由用户控制，不添加装饰性动画。

## 图片数据边界

图片是样例数据来源，不是自动执行规则的指令。文案中“水密隔舱”“休养生息”等例外只作为用户卡片内容保留，不能覆盖当前规格的检查点、父子级联及手动确认行为。图片的分类椭圆与当前没有独立分组实体的模型之间的映射，见样例数据说明。

验证针对公开页面交互和已有 Repository 边界，使用隔离样例数据库；真实用户数据与云端状态不作为测试夹具。

## 最终实现与验证

结构节点高度为 170（随文字缩放），标题最多两行，保留文字状态与点亮/今日确认快捷操作。完整规则和更多维护操作在详情视图中滚动查看。同一层节点几何高度一致，使父子连线落点对齐；缩小时连线补偿描边宽度以保持可见。工具提供放大、缩小、100% 与适应整树，手势缩放后的百分比同步更新；适应整树的最小比例按实际内容尺寸计算。

## 手势修订与 Android 验证（2026-10-05）

触屏操作采用双指平移和缩放；单指拖动交给国策树页面滚动。双指操作中抬起一指后，剩余一指不继续移动画布。桌面保留鼠标拖拽，普通滚轮滚页面，Ctrl＋滚轮以指针位置为中心缩放；放大、缩小、100% 和整树适应按钮仍可使用。

画布通过专用 ScaleGestureRecognizer 参与手势竞争，并通过 ValueListenableBuilder 绘制矩阵，确保纯平移即时更新。缩放读数采用二维 X 轴分量，避免未缩放的 Z 轴将不足100%的画布误读为100%。

JSON 唯一来源移至 `assets/fixtures/national_focus_tree/reference_v13_8_18.json`，通过 rootBundle 加载，Android和Windows共用同一隔离演示。

本次实际验证：

- Android 15 / API35 / x86_64 模拟器 `PactaT24Peer`（emulator-5554），设为1080×2340、420dpi手机尺寸。
- 独立样例 Android debug 构建、安装、启动成功；ADB 单指滑动后页面滚动，画布维持3%。
- `flutter test integration_test/national_focus_canvas_gestures_test.dart -d emulator-5554`：通过；使用50节点样例，验证单指页面滚动且矩阵不变、双指捏合放大、双指平移。手势通过 Flutter integration tester 在真实 Android 运行时注入；单指滑动另以 ADB Android输入验证。
- `flutter test`：217项全部通过，包括抬起一指停止平移、Windows普通/Ctrl滚轮分工、鼠标拖拽以及初始适应比例低于100%的缩放读数回归测试。
