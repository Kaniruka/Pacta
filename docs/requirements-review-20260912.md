- 四个主目的地；任务进度与任务完成分离；Goal → Task 两层且所有任务必做。
- 专注正常倒计时完成；例外暂停仍是同一会话；暂停时间不计进度；继续使用保留的下必为例版本；后台或进程退出本身不代表失败。

- 国策检查点固定北京时间每日 04:00，换时区只改变显示。
- 今日确认只批量点亮待确认节点；真正熄灭节点不会被批量恢复。
- 下一检查点仍未确认即正式失败；保留历史最高和内化进度。
- 主动熄灭在检查点结算，此前恢复点亮保留记录。本次修正了此前文档仍将此列为待决的错误。
- 有效离线确认不因延迟上传或服务器未收到而失败。

- D09：父子都待确认时允许单独确认子，不自动确认父。父到检查点漏确认失败，子受连带影响且当天不计成功。一键确认处理所有待确认节点，不恢复真正熄灭节点。
- D10：独立失败来源分别记事件；仅被父连带的后代不另记独立事件。子有独立来源且到检查点仍符合失败条件则保留独立事件；同节点同检查点只结算一次失败。每条事件保留完整树快照。日确认流程的批量失败只提供一个原因入口，一次填写关联本批记录；漏确认用系统原因“未完成今日确认”，可统一补充，不强制、不阻断。事件分组与原因入口数量是不同规则。
- D11：父及后代一起移入卡片库后拆散，解除父子关系，成为独立卡片；逐张选位置放回并手动点亮，无整棵子树恢复。保留卡片记录和旧快照。库中不参与一键确认；检查点前放回点亮则保留连续记录，否则按既定失败规则；从未点亮或已失败者不新增重复失败。否决上一轮助手提出的保留子树关系方案。
