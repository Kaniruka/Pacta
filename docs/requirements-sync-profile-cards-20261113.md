## 已内化判定与最终确认的增长公式

- GLOSSARY 的 Internalization Progress 是熟悉程度的展示代理，不是实际习惯形成测量；模型采用 `100 * (1 - exp(-successfulDays / 60))`，没有完成状态或达标阈值。上一轮代理推荐“已内化数量”前未核实该边界，应纠正而非擅设阈值。
- 用户曾提出严格超过100%算已内化；澄清旧渐近公式无法达到该条件后，用户允许达到100%即可。线性60天达标只是讨论中的建议，未被采用。
- 最终提案为 `I = min(100, 100 * (1 - exp(-S / 60)) / (1 - exp(-180 / 60)))`，`S` 为累计成功国策日。用户回复“可以，直接采用”。180个成功日达到100%并封顶，保留前快后慢曲线。
- 已内化直接按 `S >= 180` 判定，不以显示四舍五入值判定；熄灭不清除累计成功日，不自动升级强化要求。180天是产品标尺，不是现实习惯形成的科学结论。
- 新公式替代旧公式以及此前严格超过100%的提议；旧成功日无需迁移，展示根据既有成功日重新计算。本轮仅落地公式和模型判定，名片统计仍属于后续整体实施。
