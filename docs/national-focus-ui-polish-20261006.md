# 国策树界面修订审查（2026-10-06）

## Summary

原截图评价：Needs work；补丁复核：Good。国策树的核心是结构扫描与每日维护，但之前的补丁新增独立抬高顶栏，忽略看板、专注链和我的的一级页一致性；节点菜单又混合了状态展示、操作与折叠详情。此次直接按用户反馈修补这些视觉与交互问题，沿用Flutter Material 3及现有树的圆节点签名。

已读取用户附件与实际代码。截图可用于判断层级与视觉负担；字号、尺寸与对比度依据代码和已有主题实测，不从截图猜测精确数值。Apple HIG仅作为原则与基础，Android组件遵循Material。

## Improvements

- **High：一级页标题不一致。** `layout.md › Adaptability`：“Design a layout that adapts gracefully and consistently.” 看板、专注链、我的采用滚动内容标题headlineSmall与约20dp顶部留白；旧国策页却用elevation=1与titleLarge构造独立窄条。修复为同样的内容标题与主要/次要动作布局，不再把顶栏当独立卡片。此布局选择是本项目的一致性判断。
- **High：状态动作位置跳变。** `menus.md › Organization`：“Prefer listing important or frequently used menu items first.” 第一行稳定承载点亮/今日确认/熄灭，保留禁用原因与原熄灭确认。移除面板中的状态chip与节点编号，状态由动作语义和树图标表达，辅助技术仍可读状态。
- **Medium：菜单内折叠长详情。** `modality.md › Best practices`：“Aim to keep modal tasks simple, short, and streamlined.” 菜单只做操作选择，查看详情关闭菜单后进入独立阅读页，规则、当前强化、记录分组，标准返回维持画布位置。菜单按内容定高，不用固定82%高度撑出空白。
- **Medium：低频改名占菜单。** 改名移到库卡更多或树卡详情页更多，避免让人为了改名先移出树并解除子树关系。不是移除命名能力；菜单无改名常驻项。
- **Medium：画布控制过重。** `toolbars.md › Best practices`要求次要动作归入More。最终只保留适应屏幕图标及辅助标签，删除放大/缩小、恢复100%、缩放菜单、比例和按钮常驻文字；保留双指操作、鼠标平移和Ctrl滚轮。密度切换为有文字的视图下拉，不再用大轮廓双按钮加勾选图标。中间方案曾把辅助缩放收进更多，但用户随后要求彻底删除这些命令，最终只保留图标与手势。

## 设计计划与自审

不改全局主题，继续6个语义角色与已有浅/深色实测值：页面#F5FBF7/#0E1513、画布#EFF5F2/#171D1B、正文#171D1B/#DEE4E1、点亮圆底#A0F2DF/#005145、待确认圆底#C9E6FF/#2B4A5F、熄灭圆底#DEE4E1/#303634。正文/画布对比15.48/13.27，圆底图标最低7.20；本轮没有另造品牌配色。系统字体：内容标题headlineSmall 24sp，节点titleSmall 14sp，正常正文bodyMedium 14sp，辅助bodySmall 12sp。

这是Pacta已有树结构和一级页布局的收敛，不引入通用新皮肤。删掉的附件是独立顶栏阴影、菜单状态徽章、折叠正文、常驻缩放加减与双模式按钮的装饰。缩放适应提供即时结果，未增加装饰性动画或玻璃效果。控件维持48dp交互目标，320dp/200%字体用换行和滚动适配；详情和菜单不嵌套多层模态。
